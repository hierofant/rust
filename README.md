# rust-build-sim

Личный мобильный симулятор строительства Rust (механика 1:1: сокеты, DeployVolume, стабильность, все размещаемые предметы).

Статус: сбор данных + ядро механики.

- `sim/` — симулятор: TypeScript-порт серверной логики стройки + мобильный 3D-интерфейс.
  - `cd sim && npm i && npm test` — тесты ядра на реальных данных;
  - `npm run dev` — открыть в браузере (с телефона в той же сети: адрес, который покажет vite);
  - `npx tsx tools/compile-data.ts ../data/<buildid>` — пересобрать `public/data/` из нового дампа.

Управление на телефоне: левая половина экрана — джойстик, правая — обзор; большая кнопка — поставить
(в режиме молотка — апнуть), ⟳ — повернуть, 🔨 — режим молотка, ✕ — снести; грейды внизу — во что сразу
апать поставленный блок (долгое нажатие — скины); ▦ — слои коллизии, ◫ — объёмы постановки, ↶ — отмена.
 Задание для локального агента, который работает в папке Rust Dedicated Server, лежит в [`extraction/TASK.md`](extraction/TASK.md).

Репозиторий держать **приватным**: сюда попадает декомпилированный код и ассеты Facepunch.
